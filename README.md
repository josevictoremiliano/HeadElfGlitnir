# HeadElfGlitnir

## Descrição
HeadElfGlitnir é um mod para Valheim que adiciona um novo item ao jogo: um headpiece élfico estiloso. Este mod utiliza o framework Jotunn para facilitar a integração com o jogo base.

## Características
- Adiciona um novo item de capacete élfico "HeadElf" ao jogo
- O item é craftável na forja (forge)
- Design élfico único que se destaca dos equipamentos padrão do jogo

## Requisitos
- Valheim
- BepInEx
- Jotunn (dependência obrigatória)

## Instalação
1. Certifique-se de ter o BepInEx instalado
2. Instale o mod Jotunn
3. Coloque o arquivo HeadElfGlitnir.dll na pasta de plugins do BepInEx
4. Execute o jogo

## Como Obter
O capacete élfico pode ser craftado na forja (nível 1). Os materiais necessários para crafting são:
- SwordCheat x10
- SwordCheat x5
- SwordCheat x5

*Nota: Os requisitos de crafting são temporários e serão ajustados para recursos mais apropriados em versões futuras.*

## Compatibilidade
Este mod foi desenvolvido e testado com a versão atual do Valheim. Como o jogo é atualizado regularmente, algumas atualizações podem causar incompatibilidades.

## Desenvolvimento
Este projeto é criado com:
- C#
- Unity
- BepInEx
- Jotunn

O mod carrega um assetbundle contendo o modelo 3D e configurações do capacete élfico. O código principal gerencia o registro do item no jogo, definindo suas propriedades e requisitos de crafting.
